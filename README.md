# Puente de Mando

Panel personal de tareas, agenda y dinero. Una sola página, sin dependencias.

- **Tareas y rutinas** del día, con prioridad, área, estimación y cronómetro.
- **Agenda** mensual y semanal, con importación y exportación `.ics`.
- **Dinero**: reparto del ingreso por sobres, gastos fijos, puntuales y a plazos.
- **Balance** por semana, mes y año.

Los datos se guardan en el navegador. Si conectas GitHub desde *Ajustes → Sincronización*,
viajan además en un **gist privado** de tu cuenta, de modo que el móvil y el ordenador ven
lo mismo. El token se guarda solo en tu dispositivo y necesita únicamente el permiso `gist`.
